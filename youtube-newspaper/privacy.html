最終更新日: 2026年10月20日

対象

YouTube Newspaper（以下「本ツール」）は、運営者本人だけが使う個人用ツールです。運営者以外のアカウントは利用できません。

取得する情報と使い道

  • Google アカウントのメールアドレス: ログインした人が運営者本人かを確かめるためだけに使います。
  • YouTube の登録チャンネル・おすすめ・動画の字幕と公開情報: 要約を作って画面に表示するために使います。
  • YouTube Data API で行う操作: 運営者が画面で押した「高評価」「低評価」「保存」を、運営者自身の YouTube アカウントに反映するためだけに使います（動画の評価と、運営者の再生リストへの追加）。

保存と共有

取得した情報は、運営者が管理する Google Cloud のプロジェクト内にだけ保存します。第三者に提供・販売することはありません。 要約の作成には Google の Vertex AI を使います。

Google API から受け取る情報の扱い

本ツールが Google API から受け取った情報の使用と他のアプリへの転送は、 Google API Services User Data Policy（Limited Use の要件を含む）に従います。

削除

運営者は Google アカウントのサードパーティ アクセスから本ツールの許可をいつでも取り消せます。保存した情報は、運営者がプロジェクトのデータベースから削除します。
